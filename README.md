# propygator

A Python library for orbital simulation and satellite tracking, built on [Orekit](https://www.orekit.org/).

**Status:** Under construction. The architecture is designed (see `docs/architecture.md`); implementation is in progress.

## Planned features

- Numerical orbit propagation with configurable force models
- TLE propagation (SGP4) and fitting
- Real-time satellite tracking
- Ground-station pass prediction with visual-magnitude estimates
