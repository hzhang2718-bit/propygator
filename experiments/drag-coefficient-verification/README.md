# Drag-coefficient verification (reference only)

Empirical check of the load-bearing assumption behind propygator's variable drag
coefficient: that a spacecraft's free-molecular **C_D collapses onto a single
`(geocentric radius, total density)` surface**, independent of the epoch /
space-weather state that produced that density. If that holds, a
`(geocentric radius, density)` lookup table is a sufficient statistic for C_D and
never goes stale — which is exactly the design described in `docs/features.md`
§1.1 and generated by `docs/build-plan-feature-1.1.md` Chunk 5.

> [!NOTE]
> **Boundary-finding scope (drag-validity addendum, Chunk 1).** This study now
> maps *where* the collapse holds rather than only re-confirming the interior:
> a dense sweep ~130–1400 km **keyed on geocentric radius** (the production axis),
> a deliberate storm cohort, and the collapse RMS reported **PASS/WARN/FAIL**
> against coded thresholds (green ≤ 5 %, red ≥ 30 %; `docs/history/feature-1.1-addendum-
> drag-validity-and-altitude-guards.md` §3.1–3.6). It measures only the *high*-
> altitude (collapse) limit; the *low*-altitude model-validity floor is found by a
> separate Knudsen diagnostic the collapse metric is blind to (addendum §2, Chunk 2
> — now built; see `kn_floor.py` and "Low-altitude validity floor" below).

> [!IMPORTANT]
> **Status: reference only — not part of the package.** This is an exploratory
> reconstruction, not shipped propygator code and not the Chunk 5 deliverable
> (`scripts/generate_sphere_cd_table.py`). It is **not** imported by propygator,
> **not** run in CI, and **not** linted/type-checked. The C_D model here is a
> stand-in and will **not** be incorporated into the package (not even by copying
> lines over). It is kept as the evidence behind the design decision.

## What it tests

| Tier | Geometry | Question | Result |
|------|----------|----------|--------|
| A | sphere | Does C_D collapse onto one `(radius, ρ)` surface across genuinely different epochs (season, local solar time, latitude, F10.7, Ap) **and a storm cohort**, over **~130–1400 km**? | **Yes** — scatter at matched `(radius, ρ)` ≈ **0.49 % RMS** overall (0.67 % storm-only); **every radius band PASSes** the ≤ 5 % green line, so the high-altitude cut is **non-binding** within the sweep |
| B | box / plate | Does it still collapse **at fixed attitude**, for a cube and a thin plate from head-on to grazing? | **Yes** — ≤ ~2 % RMS even for an 80° grazing plate; all attitudes PASS |

Both are an order of magnitude under the 15–30 % thermospheric density-model
uncertainty that dominates total drag error, so keying C_D on `(radius, density)`
is sound. That the collapse stays green across the whole 130–1400 km sweep is the
expected outcome (addendum §2/§4): the high-altitude limit is soft because drag
∝ ρ → 0 there, and the collapse metric cannot see the *low*-altitude breakdown.

## How to run

The dependencies (`scipy`, `pymsis`) are intentionally **not** in the propygator
conda env — that env is a pinned, tested combination. Use a throwaway virtual
environment instead. From **this directory** (PowerShell):

```powershell
# 1. create an isolated environment (any Python 3.10–3.13 works)
python -m venv .venv-experiments

# 2. activate it (the prompt gains a "(.venv-experiments)" prefix)
.\.venv-experiments\Scripts\Activate.ps1

# 3. install the deps (prebuilt wheels — no compiler needed)
pip install -r requirements.txt

# 4. run from THIS directory (the imports are flat, not a package)
python cd_sphere_experiment.py > cd_sphere_results.txt
python cd_box_experiment.py    > cd_box_results.txt
python kn_floor_experiment.py  > kn_floor_results.txt
python cross_validate_models.py > cross_validate_results.txt

# 5. leave the environment when done
deactivate
```

The `> ...results.txt` redirect captures the full numeric output (the figures only
show summaries). Delete the `.venv-experiments/` folder to remove the environment
entirely; it is gitignored.

If `Activate.ps1` is blocked by PowerShell's execution policy, allow it for the
current session only: `Set-ExecutionPolicy -Scope Process RemoteSigned`.

## Results (local venv run, 2026-06-14)

Exact stdout from the run that produced the committed figures (regenerate any time
with the `> ...results.txt` redirect in step 4). Collapse "thickness" is the RMS %
C_D scatter at matched `(geocentric radius, ρ)`, binned in 25 km radius bands and
graded against green ≤ 5 % / red ≥ 30 %.

**Tier A — sphere** (5360 points: 67 epochs incl. 12 storm × 80 altitudes,
130–1400 km; radius 6490–7778 km):

- *Per-band scatter* rises gently from **0.15 %** RMS near 125 km to **~0.66 %**
  around 850 km, then plateaus ~0.55–0.6 % out to 1400 km. **Overall 0.490 %**,
  **storm-cohort 0.672 %** — **every band PASSes** the 5 % green line, so there is
  **no high-altitude cut within the swept range** (the high limit is non-binding).
- *Operational* — table built on 33 epochs, applied to the 34 held-out epochs:
  residual **mean +0.364 %, RMS 2.061 %**, 95th |·| 3.95 %, max |·| 13.81 % (n = 2565).

**Reading the middle panel (the "fork").** In `cd_time_independence.png` the centre
plot (C_D vs density, coloured by radius) splits into two arms at the low-density /
high-altitude end. That fork is the **oxygen→helium composition transition** seen
through the accommodation coefficient α: where atomic O dominates the gas, the SESAM
model gives α ≈ 0.9 (cold, accommodated re-emission → lower C_D); where He takes over
(~600–1000 km up) the O coverage collapses, α → 0 (hot, un-accommodated re-emission →
higher C_D). So one density value is populated by two *different* atmospheres, and
C_D swings ~6 % (up to ~30 % across the full range) between them. This is the **radius
dependence made visible**: the panel projects the radius axis out and shows it only as
colour, so a genuine C_D(radius) effect has to appear as branching, and the two arms
are different colours. It is *reassuring*, not alarming — at a fixed `(radius, ρ)` the
composition and α are pinned and C_D collapses back to one value (the < 1 % thickness
in the right panel). The fork is exactly **why the table is keyed on `(radius, ρ)` and
not density alone**: radius is the coordinate that says which arm you are on. (Verified
against the data: within a fixed-density slice, corr(C_D, α) runs −0.7 to −0.99 and the
slice is a genuine O/He mix only at the low-density end.)

**Tier B — box / plate**, collapse RMS at matched `(radius, ρ)` at fixed attitude
(storm-only RMS and worst single-bin max in the captured stdout); all PASS, no cut:

| attitude | mean C_D | RMS % | storm % |
|----------|---------:|------:|--------:|
| cube head-on (0°) | 3.601 | 1.004 | 1.232 |
| cube edge-on (45°) | 4.217 | 0.622 | 0.816 |
| cube corner-on | 4.638 | 0.374 | 0.560 |
| plate face-on (0°) | 3.134 | 0.488 | 0.784 |
| plate 60° | 1.298 | 0.368 | 0.533 |
| plate 80° grazing | 0.432 | 1.977 | 2.311 |

Sphere overall is 0.49 %; even the 80° grazing plate stays at ~2 % — all an order
of magnitude under the 5 % green line across the whole 130–1400 km sweep.

## Low-altitude validity floor (Knudsen diagnostic, Chunk 2)

The collapse study above maps only the *high*-altitude limit and is blind to the
low-altitude one by construction (addendum §2): it uses the free-molecular C_D as
its own ground truth, so the scatter stays tight *precisely where* the model starts
breaking down. `kn_floor.py` is the separate instrument for that low edge — the
altitude where a body leaves free-molecular flow and the Sentman/DRIA closed form
begins to over-predict C_D.

It computes a composition-weighted hard-sphere mean free path
`λ = 1 / (√2 · Σ_i n_i σ_i)` from the per-species NRLMSISE-00 number densities and
a documented σ table (per-species kinetic diameters; cited in the module
docstring), then the Knudsen number `Kn = λ / L` for a body of characteristic
length `L`, and scans altitude for the **free-molecular floor `Kn = 10`** at a
**conservative high-activity** atmosphere (denser → shorter λ → a higher, safer
floor). `L` is the lookup the runtime mirrors (sphere → diameter `2√(A/π)`; box →
max edge length).

**Result (local venv run, 2026-06-15), conservative high-activity (F10.7 = 250,
Ap = 45):** the floor rises monotonically with body size from **~110 km** (0.1 m
CubeSat) to **~223 km** (30 m station):

| body | L [m] | floor [km] |
|------|------:|-----------:|
| 1U CubeSat | 0.10 | 110.5 |
| 3U CubeSat | 0.34 | 118.6 |
| smallsat | 1.0 | 128.4 |
| small bus | 3.0 | 145.4 |
| large bus | 5.0 | 156.9 |
| ISS module | 10.0 | 177.2 |
| station | 30.0 | 222.5 |

Sanity checks (all PASS in `kn_floor_results.txt`): λ matches US-Standard-Atmosphere
ballpark values to an order of magnitude (0.147 m @ 100 km, 47 m @ 150 km); the
floor is monotonic in `L`; and the conservative high-activity floor exceeds the
mid-activity floor everywhere (by +0.2 km at 0.1 m up to +25 km at 30 m — solar
activity barely moves the ~110 km lower-thermosphere floor but strongly lifts the
~200 km one).

**Now wired into the runtime and cross-checked (Chunk 9).** Chunk 9 implemented this
floor in `propagation/guards.py` by re-implementing the λ/σ/`Kn`/scan method over an
offline-captured conservative-profile composition (Orekit's atmosphere exposes only
*total* density, so the per-species composition is captured offline, not queried
live — `scripts/generate_kn_floor_composition.py`). It passes the §5 cross-check
against the curve above: the recorded evidence `kn_floor_runtime_crosscheck.txt`
shows the continuous-MSIS `floor_altitude(L)` reproduces this table, and the
runtime's grid+bisection method matches it to **< 0.3 km**;
`test_runtime_floor_matches_experiment_curve` re-asserts it in the test suite. The
caveat from the Cd cross-validation does not fully carry over: this check shares the
committed composition and σ table between experiment and runtime, so it certifies the
*code port* (the independently-written λ formula and root find) rather than a second
independent physics reconstruction.

## Model cross-validation & validated band (Chunk 3)

The validity experiment (`cd_core.py`) and the **shipped** table generator
(`scripts/generate_sphere_cd_table.py`) are **two independent reconstructions** of
the same Sentman/DRIA physics — by design the generator does not copy the
experiment. A validity limit found here transfers to the shipped table **only if
the two models agree at the boundary** (addendum §5 — the single most important
correctness constraint). `cross_validate_models.py` proves it: it drives both off
one identical set of NRLMSISE-00 rows and compares.

**Result (local venv run, 2026-06-15) — the two models agree to 0.0191 % (≪ 1 %):**

| check | result |
|-------|--------|
| Shared algebra (per-species C_D + accommodation isotherm) | **0.00e+00** — bit-identical |
| Accommodation anchor → Langmuir K (α = 0.90) | K matches to **0.017 %** (cd_core's hardcoded anchor `n_O = 2.64e14, T = 1284` equals live NRLMSISE-00 `2.640e14, 1284.1`) |
| Relative-speed formula | exact at the equator; **≤ 0.16 %** at lat 80° — `cd_core.v_rel` uses a *spherical* radius `R⊕+alt`, the generator the true *geocentric* radius (a documented, sub-1 % difference that moves neither boundary) |
| **End-to-end C_D, 150 shared (condition × altitude) points, 130–1450 km, lat −60..70°** | **max 0.0191 %, mean 0.0059 %** (equator subset 1e-7) — **PASS ≪ 1 %**. The range spans the full generation band (the 150–1400 km grid *plus* the internal-sampling margin), so the extended 1400 km grid claim is certified, not just the old 1200 km |

So a limit derived from the experiment is safe to ship in the regenerated table
(Chunk 4).

**Phase-2 validated band (addendum §4)** — the constants the runtime guards and
the table regeneration read:

| quantity | value | notes |
|----------|-------|-------|
| **Lower edge** | **~150 km** (geocentric radius 6,528,000 m) | retained; not extended downward (volatile/unvalidated density below; the Knudsen floor governs low-altitude *model* validity). Size-independent — the large-satellite case is covered by the per-body Kn floor, not by raising this edge |
| **Upper edge** | **~1400 km** (radius 7,778,000 m) — *signed off 2026-06-15* | extended from the old 1200 km to the full green-validated sweep, so high/elliptical LEO no longer trips nuisance clamp warnings. The collapse stays green (≤ 5 %) throughout, so the high "cut" is **non-binding** |
| **Knudsen floor `floor_altitude(L)`** | **110.5 km** (0.1 m) → **222.5 km** (30 m) | conservative high-activity (Chunk 2); body-size-dependent runtime warning (threshold 2), separate from the table edge |

## Provenance

The C_D model here was reconstructed in a Claude analysis sandbox (~2026-06-11). The
committed figures and the numbers in "Results" above were **regenerated locally**
under the experiment venv on **2026-06-14** for the drag-validity addendum's
boundary-finding expansion (Chunk 1: radius axis, 130–1400 km sweep, storm cohort,
coded thresholds, α = 0.90) — fixed RNG seeds plus deterministic NRLMSISE-00 make
the run reproducible (given the same `pymsis`). The scripts are **not** executed in

The work originally lived in a single flat directory; it was reorganized here with
the two tiers sharing `cd_core.py`.

## Caveats (what this does and does not establish)

- **Model-based, not flight-data.** It shows that a physically reasonable
  free-molecular C_D model collapses onto `(radius, ρ)`; it presumes that model.
  Appropriate for de-risking a design choice, not a claim of absolute C_D truth.
- **Single-anchor accommodation calibration** (α ≈ 0.90 at 400 km / solar max — a
  commonly-accepted value: Pilinski et al. 2010 SESAM ~0.85–0.93, Moe & Moe 2005 /
  CHAMP ~0.86–0.89; reconciled with the table generator per the drag-validity
  addendum §5, replacing the earlier 0.82). The *collapse* conclusion is a property
  of the mechanism — α tracks atomic-O coverage, which tracks the same heating that
  sets density — not of the calibration constant. *(The committed `*_results.txt`
  are now the α = 0.90 run.)*
- **Axis.** The collapse is now analyzed on **geocentric radius** — each sample is
  converted from its geodetic `(altitude, latitude)` via the forward closed form
  mirrored from the table generator (`geocentric_radius()`), the production axis the
  shipped table keys on. (The msis *input* is still geodetic altitude/latitude, as
  it must be; only the analysis axis changed.)
- **Coverage / what this measures.** ~130–1400 km, so the `sphere_default` grid
  (~150–1200 km) is fully exercised on both sides. This locates only the **high**-
  altitude (collapse) limit, which is non-binding here. The **low**-altitude
  model-validity floor — where free-molecular flow breaks down (Kn → O(1)) and the
  collapse metric is blind by construction (addendum §2) — is **not** established by
  *this* (collapse) study; it is established by the separate Knudsen diagnostic
  (`kn_floor.py`, Chunk 2; see "Low-altitude validity floor" above).
